================================================================================
  📖 StoryBook Studio (스토리북 스튜디오) — 시작 및 설치 안내서
  "가장 개인적인 기억이 가장 깊은 문학이자 예술이 된다"
================================================================================

안녕하세요! 기억 기반 시화집 독립출판 스튜디오 'StoryBook Studio'를 찾아주셔서 감사합니다.
본 프로그램은 복잡한 설치 과정이나 전문 디자인 도구(Canva 등)를 전혀 몰라도,
어르신과 초보자 누구나 자신의 소중한 기억을 엮어 한 권의 정식 종이책 시화집(부크크 POD 300 DPI 완제본)과
맑은 노래가 흐르는 온라인 웹 시화전 갤러리를 100% 자체 완결 출판할 수 있도록 돕는 따뜻한 공방입니다.


★ [필독: 상세 사용 설명서 확인하는 방법]
--------------------------------------------------------------------------------
프로그램을 켜신 후, 화면 왼쪽 기둥(사이드바) 맨 아래에 있는
[📖 큰 글씨 사용 설명서] 버튼을 누르시면, 돋보기 없이도 시원한 큰 글씨와 정갈한 책 서식으로
시 짓기부터 노래 만들기, 종이책 출판까지의 전 과정을 아주 친절하게 안내받으실 수 있습니다!
(인터넷 주소: http://localhost:8000/manual )
--------------------------------------------------------------------------------


--------------------------------------------------------------------------------
1. 시스템 권장 사양
--------------------------------------------------------------------------------
- 운영체제: Windows 10 또는 Windows 11 (64비트)
- 웹 브라우저: Chrome, Edge, Whale 등 최신 웹 브라우저 (Chrome 권장)
- 인터넷 연결: AI 시/삽화/노래 생성 및 온라인 갤러리 감상 시 필요 (일반 집필 및 조판은 오프라인 가능)


--------------------------------------------------------------------------------
2. 프로그램 실행 방법 (무설치 포터블 — 설치 과정 없음!)
--------------------------------------------------------------------------------
본 프로그램은 윈도우 시스템이나 레지스트리를 건드리지 않는 '무설치 포터블(Portable)' 방식입니다.
복잡한 설치 마법사나 관리자 권한 승인 없이 바로 실행하실 수 있습니다.

1) 다운로드한 [StoryBook_Studio.zip] 파일의 압축을 원하는 폴더에 풉니다.
   (바탕화면이나 내 문서 등 찾기 쉬운 곳 권장)

2) 압축을 푼 폴더 안의 [시집만들기.bat] 파일을 더블 클릭(두 번 톡톡)합니다.
   ※ Windows SmartScreen("Windows의 PC 보호") 파란 화면이 나타날 경우:
      -> [추가 정보] 클릭 -> 아래의 [실행] 버튼을 클릭하시면 즉시 안전하게 열립니다.
   ※ [편리 기능] [시집만들기.bat]를 처음 실행하시면 바탕화면에 [시집만들기] 바로가기
      책 아이콘이 자동으로 생성됩니다! (다음부터는 바탕화면 아이콘만 누르시면 됩니다)
      혹은 폴더 내 [바탕화면에_바로가기_만들기.bat]를 직접 누르셔도 바로 생성됩니다.

3) 1초 후 기본 웹 브라우저가 자동으로 열리며 '스토리북 스튜디오 집필실' 화면이 나타납니다.
   (접속 주소: http://localhost:8000)

4) [종료 방법]: 열려 있는 작은 검은색 콘솔 실행 창을 닫으시면 프로그램이 깔끔하게 종료됩니다.


--------------------------------------------------------------------------------
3. 로그인 및 집필실 입장 (내 원고 안심 보호)
--------------------------------------------------------------------------------
1) 프로그램 첫 실행 시 중앙 회원 확인 화면이 나타납니다.
   - [구글로 시작하기]: 구글 계정 클릭 한 번으로 1초 만에 안전하게 가입 및 로그인됩니다.
   - [게스트로 둘러보기]: 로그인 없이 먼저 둘러보고 싶으신 경우 화면 하단의 게스트 링크를 누르세요.
2) 한 번 로그인하시면 내 PC에 안전하게 기억되므로, 다음번 실행부터는 다시 로그인할 필요 없이
   곧바로 나만의 시화집 집필실로 직행합니다.
3) 게스트 상태에서 써둔 원고가 있더라도 로그인하는 순간 내 계정 서재로 자동 귀속되므로
   소중한 원고가 지워질 염려가 전혀 없습니다.


--------------------------------------------------------------------------------
4. 초보자를 위한 3단계 시화집 출판 순서
--------------------------------------------------------------------------------
StoryBook Studio는 [시화 창작] -> [시화집 조판 편집] -> [출판 데이터 센터]의 3단계로 완결됩니다.

[1단계: 시화 창작 스튜디오 (나만의 시·그림·노래 빚기)]
- 좌측: 어린 시절 툇마루, 어머니의 온기 등 떠오르는 기억을 적거나 [🎤 마이크]로 편하게 말씀하세요.
- [✨ 시 짓기]를 누르면 정통 서정시 2편(A안 담백한 정경 시, B안 아련한 내면 시)이 완성됩니다.
- 우측: [🎨 300 DPI 서정 수채화 그리기]로 시의 정경에 꼭 맞는 수채화를 빚어냅니다.
  (가장자리가 5% 은은하게 번져 종이책과 자연스럽게 융합됩니다)
- [🎧 3대 음악 AI 작곡 (Suno · Udio · YuE2)]:
  * 1번 Suno AI (감성 1위): 매일 10곡 무료 생성, 한국어 서정 보컬 최강
  * 2번 Udio AI (무료 MP3): 클래식 가곡 & 7080 포크송, 결제 없이 웹에서 MP3 바로 무료 다운로드!
  * 3번 YuE2 AI (오픈소스): Colab 설치 없는 24GB 전용 서버 무설치 공식 웹 스튜디오
- 맨 아래 [💾 시·그림·노래 전체 최종 저장]을 누르면 원고에 즉시 영구 저장됩니다.

[2단계: 시화집 조판 편집 (실물 종이책 안착 점검)]
- 실제 종이책(국판 A5 규격)의 크기와 좌우 여백을 화면에서 실제 책장 넘기듯 감리합니다.
- 각 작품 상단에 [✅ 1페이지 안착] 초록불이 들어왔는지 확인하세요.
- 시가 길어 넘칠 때는 [A-] 글자 줄이기 단추나 상단 [⚙ 조판 설정]에서 [2페이지 연속 조판]을 누르시면 됩니다.

[3단계: 출판 데이터 센터 (부크크 1분 출판 완제본)]
- [📖 시집 출판 완결 편집실]: AI를 통해 '시인의 말(서문)', '맺음말', '뒤표지 카피'를 자동 집필하고
  앞표지 대표 삽화와 출판사, 판권지 정보를 등록합니다.
- [📚 부크크 출판 완제본 다운로드]:
  * [📄 A5 내지 완제본 PDF 받기] + [🎨 A5 표지 펼침면 PDF 받기] 클릭!
- [부크크 1분 출판 접수]: 부크크(bookk.co.kr)에 접속하여 위에서 받은 내지.pdf와 표지.pdf만 올려놓으시면
  까다로운 디자인 작업 없이 정식 종이책 출판 심사가 100% 단번에 통과되어 집으로 배송됩니다.


--------------------------------------------------------------------------------
5. Google Gemini 무료 AI 키 등록 (선택 사항 — 평생 완전 무료)
--------------------------------------------------------------------------------
※ 기존 샘플 프로젝트 감상 및 일반 조판/인쇄는 AI 키 없이도 100% 이용 가능합니다.
   나만의 기억으로 깊이 있는 서정시를 빚고 전용 프롬프트를 자동 추출하시려면,
   구글에서 무료(신용카드 등록 불필요)로 제공하는 Gemini API 키를 등록하세요.

1) 브라우저에서 Google AI Studio (https://aistudio.google.com/app/apikey) 접속 후 구글 로그인
2) 파란색 [Create API key] 버튼을 클릭하여 발급된 키(AIzaSy...)를 복사합니다.
3) 스튜디오 상단 우측의 [🔑 무료 AI 키 설정] 버튼을 클릭합니다.
4) 복사한 키를 붙여넣고 [저장 및 즉시 활성화]를 누르시면 하루 1,500회 평생 무료로 AI 집필이 가동됩니다.
※ 등록하신 키는 대표님 개인 PC 브라우저에만 암호화 저장되며, 외부 서버로 전송되지 않습니다.


--------------------------------------------------------------------------------
6. 자주 묻는 질문 (FAQ) 및 문제 해결
--------------------------------------------------------------------------------
Q1. [시집만들기.bat]를 눌렀는데 웹 브라우저가 자동으로 안 떠요!
A1. 웹 브라우저(크롬 권장)를 여신 후 주소창에 [ http://localhost:8000 ]을 직접 입력하시면 열립니다.

Q2. 더 자세한 설명서와 화면 그림을 큰 글씨로 보고 싶어요!
A2. 프로그램 화면 왼쪽 기둥 맨 아래의 [📖 큰 글씨 사용 설명서] 버튼을 누르시거나,
    웹 브라우저 주소창에 [ http://localhost:8000/manual ]을 입력하시면 돋보기 없이도 시원한
    공식 설명서가 열립니다. 상단의 [🖨️ 인쇄하기]를 눌러 종이책으로 뽑아보실 수도 있습니다.

Q3. 내 소중한 시 원고와 그림은 어디에 저장되나요?
A3. 외부 서버가 아닌 사용자의 PC 폴더 내부([projects] 폴더)에 안전하게 보관됩니다.
    컴퓨터를 포맷하거나 다른 PC로 옮기실 때는 [projects] 폴더만 복사해 두시면 모든 원고가 보존됩니다.
    화면 윗줄의 [📦 ZIP 백업] 버튼을 누르셔도 전체 원고가 압축 파일로 안전하게 백업됩니다.

Q4. 새 버전이 나오면 어떻게 업데이트하나요?
A4. 새로운 압축 파일의 압축을 푼 뒤, 기존 폴더의 [projects] 폴더만 새 폴더로 그대로 복사해 오시면
    이전에 쓰신 모든 시와 그림, 출판 설정이 100% 안전하게 유지됩니다.

Q5. 책등(두께)에 제 시집 제목과 이름이 인쇄되나요?
A5. 네! StoryBook Studio는 총 페이지 수를 0.1mm 단위로 계산하여, 책등 한가운데에
    [시집 제목(볼드) + 지은이 + 출판사명]을 정통 단행본 양식으로 100% 자동 인쇄합니다.
