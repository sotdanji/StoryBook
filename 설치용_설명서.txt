================================================================================
  📖 StoryBook Studio (스토리북 스튜디오) — 설치 및 시작 안내서
  "가장 개인적인 기억이 가장 깊은 문학이자 예술이 된다"
================================================================================

안녕하세요! 기억 기반 시화집 독립출판 스튜디오 'StoryBook Studio'를 찾아주셔서 감사합니다.
본 프로그램은 파이썬이나 복잡한 설정 없이도 누구나 자신의 기억과 시를 엮어
한 권의 아름다운 시화집(PDF)과 음악이 흐르는 온라인 웹 갤러리로 출판할 수 있도록 돕습니다.


--------------------------------------------------------------------------------
1. 시스템 권장 사양
--------------------------------------------------------------------------------
- 운영체제: Windows 10 또는 Windows 11 (64비트)
- 웹 브라우저: Chrome, Edge, Whale 등 최신 웹 브라우저 (Chrome 권장)
- 인터넷 연결: AI 삽화 생성 및 온라인 갤러리 공유 시 필요 (일반 집필은 오프라인 가능)


--------------------------------------------------------------------------------
2. 원클릭 설치 방법 (.exe)
--------------------------------------------------------------------------------
1) 다운로드한 [StoryBook_Setup.exe] 파일을 더블 클릭하여 실행합니다.
   ※ Windows SmartScreen("Windows의 PC 보호") 화면이 나타날 경우:
      -> [추가 정보] 클릭 -> 아래의 [실행] 버튼을 클릭하시면 안전하게 진행됩니다.

2) 설치 마법사 안내에 따라 [다음] 버튼을 누르면 자동으로 설치가 완료됩니다.
   - 기본 설치 경로: 사용자 로컬 폴더 또는 C:\Program Files\StoryBook Studio
   - 바탕화면에 'StoryBook Studio' 바로가기 아이콘이 자동으로 생성됩니다.

3) 설치가 끝나면 [완료]를 누르시면 프로그램이 즉시 실행됩니다.


--------------------------------------------------------------------------------
3. 프로그램 시작 및 사용 순서
--------------------------------------------------------------------------------
1) 바탕화면의 [StoryBook Studio] 아이콘을 더블 클릭합니다.
2) 잠시 후 기본 웹 브라우저가 열리며 '스토리북 스튜디오 집필실' 화면이 나타납니다.
   (주소: http://localhost:8000)
3) 원고 작성 -> AI 삽화 생성 -> 노래/음악 감상 연동 -> PDF 인쇄 및 시화 갤러리 감상을
   화면의 안내에 따라 직관적으로 이용하실 수 있습니다.
4) 프로그램을 종료하시려면 열려 있는 작은 실행 창(검은 창 또는 트레이)을 닫으시면 됩니다.


--------------------------------------------------------------------------------
4. Google Gemini API 키 및 최신 AI 모델 설정 (100% 무료)
--------------------------------------------------------------------------------
※ 기존 샘플 프로젝트(노을빛 기억 등) 감상 및 일반 집필은 API 키 없이도 가능합니다.
   최신 고지능 AI로 나만의 시를 빚고, 300 DPI 출판 삽화 프롬프트를 자동 추출하려면
   구글에서 평생 무료(신용카드 불필요)로 제공하는 Gemini API 키를 등록하세요.

1) 브라우저에서 Google AI Studio (https://aistudio.google.com/app/apikey) 접속 후 구글 로그인
2) 파란색 [Create API key] 버튼을 눌러 무료 API 키(AIzaSy...)를 복사합니다.
3) StoryBook Studio 화면 상단 우측의 [🔑 무료 AI 키 설정] 버튼을 클릭합니다.
4) 원하는 AI 모델(기본 추천: 최신 'Gemini 3.8 Flash')을 선택하고 키를 붙여넣은 뒤 [저장 및 활성화]를 누릅니다.


--------------------------------------------------------------------------------
5. 온라인 시화 갤러리 서버 공유 방법
--------------------------------------------------------------------------------
완성된 시화집은 가족, 친지, 독자들에게 웹 링크나 카카오톡으로 바로 공유할 수 있습니다.

1) 집필실 화면에서 [웹 갤러리 내보내기] 버튼을 클릭합니다.
2) 생성된 [gallery_dist] 폴더의 압축파일을 받습니다.
3) 무료 웹 호스팅(Cloudflare Pages / GitHub Pages / Vercel 등)에 드래그하여 올리면
   나만의 전용 시화 갤러리 주소(예: https://my-poem.pages.dev)가 즉시 만들어집니다!
4) 스마트폰이나 태블릿에서도 아름다운 시와 그림, 음악을 감상할 수 있습니다.
5) 갤러리 화면 좌측에 [📖 시화집 PDF 다운로드] 버튼이 내장되어 있어,
   독자나 가족이 원할 경우 고화질 PDF를 다운받아 집에서 출력하거나
   인쇄소에 맡겨 실제 종이책으로 복사/제본할 수 있습니다.


--------------------------------------------------------------------------------
6. 자주 묻는 질문 (FAQ) 및 문제 해결
--------------------------------------------------------------------------------
Q1. 실행 아이콘을 눌렀는데 브라우저가 자동으로 안 떠요!
A1. 웹 브라우저(크롬 등)를 켜신 후 주소창에 [ http://localhost:8000 ]을 직접 입력해 보세요.

Q2. 포트 충돌(Port already in use) 메시지가 떠요!
A2. 프로그램이 다른 포트(8001, 8002 등)를 자동으로 찾아 열어주므로 화면에 표시된
    주소로 접속하시면 정상 작동합니다.

Q3. 내 소중한 시 원고와 그림은 어디에 저장되나요?
A3. 사용자의 PC 내부(프로그램 설치 폴더 내 projects 폴더)에만 안전하게 보관됩니다.
    외부 서버로 원고가 무단 유출되지 않으니 안심하세요.

Q4. 새로운 업그레이드 버전(예: v1.1)이 나오면 어떻게 하나요?
A4. 기존 프로그램을 삭제하실 필요가 전혀 없습니다!
    새로운 [StoryBook_Setup_v1.1.exe] 파일을 그대로 실행하시면 엔진만 최신으로
    자동 업데이트되며, 이전에 작성하신 모든 시, 그림, 설정은 100% 안전하게 유지됩니다.

Q5. 프로그램을 완전히 삭제하고 싶어요.
A5. 윈도우 [설정] -> [앱 및 기능] -> [StoryBook Studio]에서 '제거'를 누르시면
    깔끔하게 삭제됩니다. (작성하신 원고는 보호를 위해 삭제되지 않고 보존됩니다.)
