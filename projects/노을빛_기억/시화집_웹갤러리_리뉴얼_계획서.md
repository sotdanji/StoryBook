# 🎨 『노을빛 기억』 시화 갤러리 웹페이지 UI/UX 리뉴얼 계획서

- **작품명**: 『노을빛 기억 — 그림과 노래가 되는 시』
- **대상 파일**: `projects/노을빛_기억/시화집_갤러리.html`
- **목적**: 기존 카드 나열식 그리드 뷰에서 **"좌측 사이드바 + 우측 분할 뷰포트(시화/음악 통합)"** 형태의 고품격 인터랙티브 디지털 시집 뷰어로 전면 리뉴얼
- **작성일**: 2026-10-07

---

## 1. 리뉴얼 배경 및 핵심 목표

### 1.1 현재 구조의 한계
- 기존 웹페이지는 9개의 카드가 단순 세로/가로 그리드로 나열되어 있어, 스크롤이 길어지고 특정 에피소드를 한눈에 탐색하기 불편함.
- 시의 분량이 길어질 경우 카드 크기가 불규칙해지고, 그림과 시의 몰입감이 분산됨.

### 1.2 리뉴얼 목표
1. **도서관/서재형 2단 레이아웃 (Sidebar + Main Content)** 도입
2. **목차 기반 즉시 이동**: 좌측 사이드바의 목차 목록상자에서 클릭 한 번으로 원하는 시화로 직관적 전환
3. **그림 포함 토글 스위치 (Dual View Mode)**: 독자의 취향에 따라 '그림+시 시화 모드'와 '순수 시집 낭독 모드'를 자유롭게 전환
4. **시 본문 독립 스크롤**: 화면 높이에 딱 맞는 안정적인 뷰포트 안에서 긴 시도 깔끔하게 스크롤 감상
5. **음악 & 가사 통합 플레이어**: 제03화처럼 노래가 준비된 에피소드에 감성적인 국악 BGM 플레이어 및 가사 토글 제공

## 3. 세부 영역별 상세 기능 명세

### 3.1 좌측 사이드바 (Left Sidebar)
- **너비**: 고정 320px (태블릿/모바일에서는 오프캔버스 햄버거 메뉴로 전환)
- **헤더 브랜딩**:
  - `큰제목`: **노을빛 기억** (30px, Bold, 따뜻한 먹물 브라운 `#3e2723`, 명조/바탕 계열 서체)
  - `소제목`: **그림과 노래가 되는 시** (14px, 차분한 베이지 톤 `#8d6e63`, 세련된 자간)
- **목차 목록상자 (Episode Selector)**:
  - 제01화부터 제09화까지의 에피소드 리스트
  - 노래가 탑재된 화(예: 제03화)에는 우측에 작은 음표 뱃지(`🎵`) 표시
  - 선택된 항목은 고급스러운 한지 브라운 하이라이트 및 골드 좌측 인디케이터 바 적용
- **명령 제어 스위치 & 내비게이션 (Controls)**:
  - **`그림 포함` 슬라이드 토글 스위치**:
    - **ON (기본값)**: 우측 본문이 `[그림 50% | 시 본문 50%]` 좌우 2열 배치로 출력
    - **OFF**: 그림 영역이 부드럽게 사라지고, 시 본문이 중앙 1열(최대 너비 760px)로 확대되어 가독성 높은 순수 시집 낭독 모드로 전환
  - **`앞으로 / 뒤로` 이동 버튼 (Prev / Next)**:
    - `◀ 이전 시` / `다음 시 ▶` 버튼으로 순차 감상 지원 (화면 버튼 클릭 및 키보드 좌우 방향키 연동)
    - 현재 에피소드 위치 인디케이터 (예: `3 / 9`) 표시

### 3.2 우측 메인 본문 (Right Main Content)

#### [영역 A] 좌측: 고화질 그림 (삽화 영역)
- **비율 및 크기**: 인쇄 원본 비율(3:4 수채화)을 유지하며 부드러운 액자 테두리와 은은한 그림자 적용
- **인터랙션**:
  - 마우스 호버 시 미세한 확대 효과 (`scale(1.02)`)
  - 그림 클릭 시 전체 화면 라이트박스(확대 팝업) 실행

#### [영역 B] 우측: 시 본문 (텍스트 뷰어 영역)
- **독립 스크롤링 (`overflow-y: auto`)**:
  - 화면 높이(`100vh` 또는 고정 뷰포트)를 벗어나지 않도록 설계
  - 시 문장이 긴 경우에도 전체 창이 밀리지 않고 시 본문 영역만 부드러운 커스텀 스크롤바로 깔끔하게 상하 스크롤
- **타이포그래피**:
  - 한국어 서정 명조체 (`Nanum Myeongjo` / `KoPub Batang`) 적용
  - 감상에 최적화된 줄간격(`line-height: 2.1`)과 자간 조정

#### [영역 C] 하단: 음악 플레이어 & 노랫말 뷰어 (노래가 있는 에피소드 전용)
- **조건부 렌더링**: 음원(`03_마지막상여.mp3` 등)이 연결된 에피소드에서만 활성화
- **오디오 플레이어**:
  - 모던한 슬림 국악풍 플레이어 바 (재생/일시정지, 프로그레스 바, 볼륨)
- **노래 가사보기 버튼**:
  - 클릭 시 하단 또는 우측에서 슬라이드로 애절한 민요조 노랫말 카드 전개
  - 시 원문과 노랫말을 동시에 대조하며 감상 가능
