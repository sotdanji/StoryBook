## 🗺️ 4. 도서 구성안 및 5부 연작 서사 목차 가이드

전체 35편의 작품은 목화 재배부터 옷 짓기까지의 전통 직조 공정을 뼈대로 삼고, 3가지 시선(어린이/아버지/조부)이 교차하는 5부(Chapter) 연작 서사로 구성합니다.

```
[권두] 표제지(속표지) ➔ 시인의 말(서문) ➔ 전체 목차
  ▼
[본문]
  제1부: 흙과 솜꽃         (목화 파종, 개화, 다래 따먹기, 솜 수확)          ― 7편
  제2부: 밤을 잣는 손       (씨아질, 활 솜타기, 고치말이, 호롱불 물레질)       ― 7편
  제3부: 바람과 불의 길     (날틀의 베날기, 마당의 베매기, 된풀과 볏짚불)     ― 7편
  제4부: 덜커덩, 세월을 짜다 (도투마리 올리기, 베틀 직조, 바디와 북, 어머니의 노래) ― 7편  ※ [제01화 새벽 대청] 수록
  제5부: 살을 덮는 온기     (잿물 삶기와 바래기, 다듬이질, 바느질, 옷 입히기)  ― 7편
  ▼
[권말] 에필로그(맺음말: 손주에게 건네는 이야기) ➔ 판권지(간기면)
```

## 📐 5. 내지 조판 상세 규격 (Canva 펼침면 구조)

### (1) 2페이지 펼침면(Spread) 레이아웃 원칙
- **좌측 페이지 (짝수면, Even)**: **[전면 삽화 페이지]**
  - 한국적 서정 수채화 삽화 배치
  - 배경 여백을 부드럽게 살려 시를 읽기 전 시각적 몰입과 여운 유도
  - 활자, 제목, 페이지 번호 일체 배제 (또는 하단 미니멀 쪽번호)
- **우측 페이지 (홀수면, Odd)**: **[시 본문 페이지]**
  - 상단: `[제01화]` 작은 표기 + `「시 제목」` (명조체 계열, 18~20pt)
  - 본문: 행/연 구분을 살린 시 원고 (KoPub바탕 / 나눔명조 10~11pt, 자간 0, 행간 1.7~1.8)
  - 하단 여백: `기억의 실마리` 1~2줄 에세이 노트 (9pt, 옅은 회색조)

### (2) 판형 및 인쇄 여백 수치 (A5: 148 × 210 mm)
- **도련 포함 캔버스 크기**: **`154 × 216 mm`** (사방 3mm 여백 포함)
- **제본 안쪽 여백 (책이 접히는 중앙부)**: **최소 20 ~ 25 mm** (글자가 접혀 들어가지 않도록 필수 확보)
- **바깥쪽 / 위 / 아래 여백**: 최소 **15 mm** 이상 확보

## 🎨 7. 표지(Cover) 정밀 설계 규격 (80페이지 기준)

1. **책등(세네카) 두께 산출 공식**:
   - 백색 모조 100g 기준 페이지당 두께: 약 `0.06mm`
   - 본문 80p = 40장 × 0.06mm = **약 2.4 ~ 3.0 mm** (여유 고려)
   > *참고*: 80p 내외는 책등이 얇으므로 책등에 무리하게 글자를 넣지 않고 깔끔한 단색으로 마감하거나, 부크크 표지 계산기 확정 수치(주문 직전)를 최종 적용합니다.
2. **표지 전체 펼침면 캔버스 크기 (Canva)**:
   - 가로 = `뒤표지(148) + 책등(약 3mm) + 앞표지(148) + 사방 도련(6mm)` = **`305 mm`**
   - 세로 = `210 + 사방 도련(6mm)` = **`216 mm`**
3. **바코드 필수 보호 구역**:
   - 뒤표지 우측 하단 `50 × 35 mm` 영역은 부크크 ISBN 바코드가 자동 인쇄되므로 완전한 흰색/단색 여백으로 비워둠.
