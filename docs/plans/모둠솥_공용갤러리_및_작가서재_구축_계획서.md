# [계획서] 모둠솥 공용 갤러리 및 회원 작가 서재(Bookshelf) 구축 계획서

> **작성 일자**: 2026-11-10  
> **문서 버전**: v1.0  
> **핵심 목표**: 
> 1. 시화집 갤러리에서 고용량 노래·영상을 완전히 배제하고 **초경량 감성 시낭송(5~8MB)**으로 전면 개편  
> 2. [시화 창작] 탭에서 생성된 노래/영상은 갤러리와 분리하여 **개인 소장용 즉시 다운로드(MP3/MP4)**로 독립화  
> 3. 회원 ID 기반의 **[1인 1나의 서재(Author's Bookshelf)]** 체계를 확립하여, 완성작뿐만 아니라 외부 소장 e-Book 및 출간작도 함께 전시·자랑할 수 있는 열린 디지털 문학관 포털 구축

---

## 1. 추진 배경 및 기획 철학

### 1) 배경 및 핵심 통찰
* **초경량 서정 미학의 회복**:
  * 동영상(편당 10~30MB)과 노래 음원은 전체 시집 패키지 용량을 수백 MB로 부풀려 모바일 열람과 서버 운영에 큰 부담을 주었습니다.
  * 시화집의 본질인 **글(시) + 그림(수채화) + 낭송(호흡과 목소리)**에 집중하여, 전체 시집을 5~8MB 수준의 초경량 패키지로 다이어트합니다.
* **창작물의 독립 소장권 보장**:
  * [시화 창작] 단계에서 AI로 생성한 노래(Suno 등)나 모션 영상은 갤러리 번들에 억지로 묶지 않고, 작가가 개인 PC나 스마트폰에 직접 소장하고 SNS에 자랑할 수 있도록 **개별 다운로드 기능**으로 전환합니다.
* **회원 ID 중심의 '열린 작가 서재' (User Insight)**:
  * "시집을 다 완성하기 전에는 아무것도 할 수 없는 폐쇄적인 구조"에서 탈피합니다.
  * 회원가입을 마친 작가에게는 즉시 **고유 서재(`my-bookshelf`)**가 부여되며, 과거에 출판한 종이책(부크크 POD), 타 플랫폼 전자책(Heyzine 플립북, 교보 eBook, 브런치북) 링크를 먼저 꽂아둘 수 있습니다.
  * 이는 초기 사용자 이탈을 막고, 현재 앱에서 짓고 있는 차기 시화집에 대한 강력한 집필 동기를 부여합니다.

## 2. 전체 아키텍처 및 3단계 전시 계층

```
[1계층: 모둠솥 공용 갤러리 포털 (/gallery)]
   │  - 전체 작가들의 출품작이 서가 형태로 모이는 온라인 문학관 메인
   │  - [정통 3D 시화집] + [작가 소장 외부 도서] 함께 전시 (배지로 구분)
   │  - 검색 / 최신순 정렬 / 필터링 제공
   │
   ├──────▶ [2계층: 작가 개인 서재 (/author/{user_id})]
   │           - 특정 작가의 모든 작품 포트폴리오를 한눈에 보는 독립 서재
   │           - 작가 프로필(필명, 소개글) + 출품 시화집 + 외부 출간 도서 목록
   │           - 가족/지인에게 링크(URL) 하나로 자랑하는 개인 문학관
   │
   └──────▶ [3계층: 작품 개별 열람]
               ├─ 모둠솥 정통 시화집 ──▶ [3D/2-Layer 넘겨보기 뷰어] (/gallery/view/{book_id})
               │                           └─ 수채화 배경 + 명조 본문 + 잔잔한 시낭송(MP3)
               └─ 작가 소장 외부 도서 ──▶ [새 탭(외부 링크) 연결] (부크크/Heyzine/교보문고 등)
```

## 3. 부문별 세부 실행 과제

### 과제 1. [시화 창작] 탭 노래·동영상 분리 및 개인 소장용 다운로드

* **갤러리 연동 완전 절단**:
  * 갤러리 데이터 페이로드(`gallery_builder.py`) 및 웹 배포 ZIP(`project_manager.py`)에서 `videos/`, `music/`, `lyrics` 수집 코드 완전 배제.
  * 갤러리 뷰어(`gallery_standalone.html`)에서 비디오 버튼, 모달, 음악 재생 탭 제거.
* **[시화 창작] 탭 독립 다운로드 UI 구축**:
  * 생성된 노래 음원: `[🎵 노래 MP3 다운로드]` 버튼 제공 (클릭 시 브라우저 직접 다운로드).
  * 생성된 영상: `[🎬 모션영상 MP4 다운로드]` 버튼 제공.
  * 작가 본인이 카카오톡, 유튜브, 인스타그램 등에 자유롭게 공유할 수 있는 개인 미디어 에셋으로 포지셔닝.

---

### 과제 2. 갤러리 초경량화 및 시낭송 전용 플레이어 안착

* **초경량 5~8MB 패키지**:
  * 30편 기준 고해상도 수채화 웹 최적화 이미지 + 초경량 낭송 오디오만 탑재.
  * 1초 이내 초고속 로딩 및 모바일 데이터 제로에 가까운 환경 구현.
* **단일 원클릭 감성 시낭송 바**:
  * 복잡한 음악/가사 선택기를 없애고, 책장 하단에 단정한 미니멀 낭송 바 안착.
  * 작가 육성 녹음(`voice_user_file`) 우선 재생 ➔ 없으면 AI 서정 낭송(`voice_tts_file`) 자동 매칭.
  * 책장을 넘기면 해당 페이지의 시낭송이 은은하게 동기화되어 흐르는 몰입형 독서 환경.

---

### 과제 3. [모둠솥 공용 갤러리 메인] 포털 (`/gallery`) 구축

* **디지털 문학관 서가(Bookshelf) UI**:
  * 우드 톤의 따뜻한 서가 매대에 입체 시집 표지들이 진열된 카드 그리드 레이아웃.
  * **서가 카드 표기 요소**:
    1. 입체 시집 표지 썸네일
    2. 시집 제목 및 시인(작가) 필명 (클릭 시 작가 서재로 이동)
    3. 대표 시 1구절 발췌 미리보기
    4. 출품 유형 배지:
       * `[🎙️ 모둠솥 3D 시화집]` (우리 앱 제작)
       * `[🔗 작가 소장 e-Book]` (외부 전자책)
       * `[🛒 서점 정식 출간작]` (부크크/교보문고 등)
    5. `[📖 펼쳐보기]` 또는 `[🌐 도서 보기]` 버튼
* **서가 기능**:
  * 작품 검색 (시집 제목, 작가명, 시 본문 키워드)
  * 정렬 옵션 (최신 출품순, 가나다순)

---

### 과제 4. 회원 ID 기반 [작가 개인 서재] (`/author/{user_id}`) 구축

* **1인 1나의 서재 (My Bookshelf)**:
  * 회원가입 완료 시 모든 회원에게 고유 URL(`/author/{user_id}`) 자동 발급.
  * 아직 완성된 시화집이 없어도, 본인의 프로필과 과거 출간작/소장 e-Book을 먼저 등록하여 서재를 꾸밀 수 있음.
* **구성 요소**:
  * **작가 헤더**: 프로필 사진, 작가 필명, 한 줄 소개(시인의 말), 집필 중인 차기작 알림.
  * **전시 서가**: 해당 작가가 출품한 '모둠솥 시화집' + '소장 도서 링크' 모음.
  * **공유 기능**: `[📋 내 서재 주소 복사]` 버튼으로 가족, 지인들에게 카카오톡 간편 공유.

---

### 과제 5. 출품 및 서재 관리 시스템 (마이페이지/조판실)

* **모둠솥 시화집 1-클릭 출품**:
  * 조판실 상단 `[🚀 모둠솥 갤러리 출품]` 클릭 시, 현재 프로젝트의 완성본이 작가의 서재 및 공용 갤러리에 즉시 등록.
  * 시 원고나 조판을 수정한 후 다시 `[출품]`을 누르면 **최신 개정판으로 자동 덮어쓰기 갱신**.
* **소장 도서(외부 링크) 등록 모달**:
  * 마이페이지 또는 조판실 사이드바에서 `[➕ 내 다른 책(외부 e-Book) 등록]` 클릭:
    * 필수 입력: 책 제목, 시인/필명, 표지 이미지, 외부 열람/구매 링크 URL, 간단한 소개글.
    * 등록 즉시 작가의 서재에 새로운 책으로 꽂힘.
* **공개 / 비공개 토글**:
  * 작가가 원할 때 언제든 본인의 출품작을 '공개' ↔ '비공개(출품 취소)'로 즉시 전환 가능.

## 4. 데이터베이스 및 엔티티 설계 (Turso SQLite)

```sql
-- 1. 작가 프로필 테이블
CREATE TABLE IF NOT EXISTS author_profiles (
    user_id TEXT PRIMARY KEY,           -- 회원 고유 ID
    pen_name TEXT NOT NULL,             -- 시인 필명
    bio TEXT,                           -- 작가 소개글
    avatar_url TEXT,                    -- 프로필 이미지
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. 서가 출품작 테이블 (자체 시화집 + 외부 링크 도서 통합 관리)
CREATE TABLE IF NOT EXISTS bookshelf_items (
    item_id TEXT PRIMARY KEY,           -- 작품 고유 ID (UUID)
    user_id TEXT NOT NULL,              -- 소유 작가 ID (FK)
    book_type TEXT NOT NULL,            -- 'internal_storybook' | 'external_ebook' | 'published_book'
    title TEXT NOT NULL,                -- 시집/도서 제목
    author_name TEXT NOT NULL,          -- 표기될 작가명
    cover_image_url TEXT NOT NULL,      -- 표지 이미지 경로
    excerpt TEXT,                       -- 대표 시 1구절 발췌
    view_url TEXT,                      -- 외부 링크 URL (자체 시화집인 경우 NULL)
    project_id TEXT,                    -- 자체 시화집인 경우 연동 프로젝트 ID
    is_published INTEGER DEFAULT 1,     -- 공개(1) / 비공개(0)
    has_recite INTEGER DEFAULT 0,       -- 시낭송 수록 여부(1/0)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES author_profiles(user_id)
);
```

## 6. 기대 효과

1. **플랫폼 신뢰도 및 만족도 급상승**:
   * 노래/영상의 과도한 대기 시간과 모바일 버벅임이 사라지고, 책장을 넘기며 잔잔한 시낭송을 듣는 정통 시화집의 감동 완성.
2. **첫날부터 활동 가능한 열린 커뮤니티**:
   * 시집 제작이 진행 중인 신규 회원도 본인의 과거 작품이나 포토북을 등록하여 즉시 자랑할 수 있어 회원 참여도 극대화.
3. **지속 가능한 서버 운영 (비용 최소화)**:
   * 대용량 미디어 스트리밍 서버 비용 부담이 사라지고, Netlify/Cloudflare 수준의 무료/초저비용 인프라로도 수천 명의 서가를 쾌적하게 서비스 가능.
