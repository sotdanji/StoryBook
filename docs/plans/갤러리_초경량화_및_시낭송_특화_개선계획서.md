# 갤러리 초경량화 및 시낭송 특화 개선 계획서

> **작성 일자**: 2026-11-10  
> **목적**: 갤러리에서 서버 트래픽과 용량을 과도하게 차지하는 노래(음원) 및 동영상(MP4) 서비스를 완전히 제거하고, 문학적 서정과 감동을 극대화하는 **‘시낭송(AI 성우 낭송 + 작가 육성 낭송)’** 전용 초경량 디지털 갤러리로 전면 개편

---

## 1. 추진 배경 및 개편 방향

### 1) 배경 및 문제점
- **시화집의 본질**: 시화집은 글(시)과 그림(삽화), 그리고 시어의 호흡을 전달하는 낭송이 어우러지는 전통 서정 예술입니다.
- **용량 및 트래픽 과부하**:
  - 기존 갤러리에 포함되어 있던 **동영상(MP4, 편당 10~30MB)**과 **AI 노래(Suno MP3, 편당 5~8MB)**는 전체 시집 배포 시 수백 MB~1GB에 달하는 막대한 용량을 차지했습니다.
  - 이로 인해 모바일 열람 시 데이터 소모, 초기 로딩 지연, 서버 스토리지 및 네트워크 대역폭 비용이 급증하는 문제가 있었습니다.
- **사용자 확정 지침**:
  - 시화집 서비스의 본질에 집중하기 위해 **노래와 동영상 서비스를 영구 배제**하고, **오직 시낭송(음성 TTS 및 작가 육성 낭송)만 지원**하기로 결정.

### 2) 핵심 개편 목표
1. **용량 95% 다이어트**: 전체 갤러리 배포 패키지 용량을 기존 수백 MB ➔ **3~10MB 수준(삽화 + 가벼운 낭송 음원)**으로 초경량화.
2. **초고속 반응형 로딩**: 첫 접속 시 1초 이내에 책장이 열리며, 스마트폰/태블릿/PC 어디서나 쾌적한 감상 보장.
3. **시낭송 전용 감성 플레이어**: 복잡한 노래/가사 탭을 없애고, 책장을 넘기면 은은하게 시인의 음성이 흐르는 단일 낭송 플레이어 안착.

### ✨ 신규 및 고도화 항목 (Enhancements)

#### 1. 단일 원클릭 감성 시낭송 바 (`[🎙️ 시 낭송 듣기]`)
- **스마트 오디오 매칭**:
  - 작가가 직접 마이크로 녹음한 육성(`voice_user_file`)이 있으면 ➔ **`[🎙️ 시인 육성 낭송]`** 우선 재생.
  - 육성이 없으면 Gemini/Edge TTS로 생성된 서정 낭송(`voice_tts_file` / `recite_file`) ➔ **`[🎧 AI 서정 낭송]`** 재생.
- **간결한 플레이어 UI**:
  - 복잡한 3단 탭(AI/음악/노래)을 없애고, 오직 **재생/일시정지 + 타임라인 진행 바 + 볼륨 조절**만 깔끔하게 노출.
  - 책장 하단이나 플로팅 바로 배치하여 시 본문과 그림을 가리지 않음.

#### 2. 목차(TOC) 및 메인 뷰어 정돈
- 목차 리스트에서 복잡한 멀티미디어 태그를 없애고, **`[🎙️ 낭송]`** 배지만 단정하게 표기.
- 이번에 정비한 **2-Layer 조판 미학(A5 펼침면 여백, 인쇄안전마진, 행간/자간)**이 갤러리 가상 책장 넘기기에서도 그대로 아름답게 표현되도록 동기화 점검.

#### 3. 초경량 웹 배포 ZIP 패키지 (`export_gallery_web_zip`)
- 압축 파일 구조 단순화:
  ```
  {시집명}_온라인갤러리_웹배포용.zip
  ├── index.html                   (갤러리 독립 실행 파일)
  ├── 배포가이드_클릭하여열기.html   (무료 배포 안내)
  ├── README_웹배포_안내.txt        (안내 문서)
  ├── images/                      (표지 및 수채화 삽화)
  └── recites/                     (가벼운 낭송 음원 .wav / .mp3만 포함)
  ```
- **용량 절감 효과**: 기존 150~300MB ➔ **평균 5~8MB 수준**으로 축소되어 Netlify / GitHub Pages에 1초 만에 무료 배포 가능.

## 3. 코드 수정 영향 범위 (Impact Scope)

1. **`core/gallery_builder.py`**:
   - `build_project_gallery_payload()`: video/song/lyrics 관련 불필요한 필드 정리.
   - `recite_f` (육성 또는 TTS) 중심의 단일 오디오 페이로드(`recite_audio`, `recite_type`)로 정돈.
2. **`web/templates/gallery_standalone.html`**:
   - 상·하단 비디오 버튼 및 비디오 모달 스크립트 완전 삭제.
   - 플로팅 오디오 드로어(`floating-audio-drawer`)의 노래/가사 탭 제거 ➔ 서정적인 낭송 전용 플레이어로 리팩터링.
   - 목차(TOC) 렌더링 함수에서 비디오/노래 아이콘 렌더링 코드 정리.
3. **`core/project_manager.py`**:
   - `_collect_project_media_into_dir()`: `videos/` 및 `music/` 노래 파일 수집 배제, 오직 `images/`와 `recites/`만 수집.
   - `export_gallery_web_zip()`: ZIP 압축 시 불필요한 폴더 제거.

## 4. 단계별 실행 계획

```
[1단계: 페이로드 정리] ➔ [2단계: 갤러리 HTML 비디오·노래 제거] ➔ [3단계: 낭송 전용 플레이어 완성] ➔ [4단계: 배포 패키지 경량화 & 동작 검증]
```

- **Step 1: 데이터 백엔드 경량화 (`core/gallery_builder.py`)**
  - 불필요한 영상/노래 데이터 바인딩 제거 및 시낭송 단일 오디오 소스 정돈.
- **Step 2: 갤러리 템플릿 UI 다이어트 (`web/templates/gallery_standalone.html`)**
  - 영상 모달, 비디오 버튼, 가사 보기, 음악 탭 완전 제거 (코드 약 400여 줄 슬림화).
- **Step 3: 서정 시낭송 플레이어 UI 안착**
  - 시인의 목소리와 배경 한지 질감이 어우러지는 단정한 낭송 컨트롤러 구성.
- **Step 4: 검증 및 배포 테스트**
  - 사이드바 `[내 시집 넘겨보기]` 클릭 시 즉시 열리는지 확인.
  - 시낭송 재생 및 책장 넘김 동기화 점검.
  - `웹 배포용 ZIP` 다운로드 용량이 수 MB대로 초슬림화되었는지 확인.
