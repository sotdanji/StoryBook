# [StoryBook] 시화집 비디오 엔진 통합 및 리엔지니어링 계획서 (v2.0)
> **부제**: 용량 최소화 · 스튜디오 좌측 사이드바 원클릭 연동 · 초간편 음성 전용 파이프라인 구축

---

## 1. 기본 철학 및 핵심 전략

> **“시(詩)와 그림(画)이 주인공이며, 영상과 음악은 시의 여운을 극대화하는 미디어 양념이다.”**

- **경량화(Lightweight) & 단순화(Simplicity)**:
  - 사용자는 자막 싱크나 비디오 코덱 같은 복잡한 기술을 일절 신경 쓸 필요가 없습니다.
  - **오직 '어떤 목소리(음성)'를 쓸지만 결정**하면, 시스템이 해당 화의 시 원고와 삽화를 결합하여 Full HD 영상을 100% 자동으로 구워냅니다.
- **StoryBook Studio UI 일체화**:
  - 외부 폴더나 콘솔창을 켤 필요 없이, **스튜디오 왼쪽 사이드바(Left Sidebar)**에서 클릭 한 번으로 모든 작업이 완료됩니다.
- **자체 엔진 내재화(Re-engineering)**:
  - 외부 Remotion 엔진(`MusicStep`)을 역공학하여, 불필요한 라이브러리를 쳐내고 한국 정통 시화집에 최적화된 경량 엔진으로 탈바꿈합니다.

## 2. 3대 핵심 요구사항 반영 설계

```
┌────────────────────────────────────────────────────────────────────────┐
│  [사용자 경험: 30초 완성]                                              │
│  좌측 사이드바에서 [음성 소스 선택] ➔ [영상 제작 클릭] ➔ [1분 뒤 완성!] │
└────────────────────────────────────────────────────────────────────────┘
```

### ① 시스템 및 영상 용량 최소화 (Ultra-lightweight Architecture)
1. **임시 파일 자동 청소 (Zero Residual Footprint)**:
   - 렌더링 과정에서 생기는 브라우저 캐시, 오디오 스펙트럼 임시 json, 중간 프레임 파일, 로그 파일(`details.log`)은 **렌더링 완료 즉시 100% 자동 영구 삭제**하여 디스크 낭비를 차단합니다.
2. **출력 비디오 슬림 인코딩 (Slim MP4 Profile)**:
   - 정지 삽화와 서정적 자막 중심의 시화 영상 특성에 맞춘 최적 인코딩 적용:
     - 코덱: H.264 (CRF 24, Preset: Medium)
     - 오디오: AAC 128~192kbps VBR
   - **용량 감량 효과**: 기존 1분당 18~35MB ➔ **1분 영상 기준 5~8MB 내외(기존 대비 60% 이상 슬림화)**로 가벼워져 모바일 전송 및 웹 로딩이 획기적으로 빨라집니다.
3. **Whisper AI 모델 경량화**:
   - `faster-whisper`의 **base (140MB int8 양자화)** 또는 **tiny (70MB)** 모델을 활용하여 RAM 사용량 200MB 미만, CPU 부하 최소화.

### ② 스튜디오 좌측 사이드바(Left Sidebar) 명령 센터 배치
사용자가 항상 바라보는 `index.html`의 `<aside class="app-sidebar">` 내부 하단에 직관적인 **[🎬 시화 영상 제작 패널]**을 신설합니다.

```text
┌──────────────────────────────────────────────┐
│  📖 StoryBook Studio (사이드바)              │
│  ├─ 📂 제11화 「따순 굼턱」 [선택됨]           │
│  ├─ 🎨 삽화: 수묵담채화 (준비 완료)          │
│  │                                           │
│  └─ 🎬 시화 영상(비디오북) 제작              │
│     ├─ 🎙️ 음성 소스 선택                     │
│     │  (o) 1. 내장 TTS 낭송                  │
│     │  ( ) 2. 내 육성 녹음본                │
│     │  ( ) 3. Suno / 외부 음악 녹음         │
│     │                                        │
│     ├─ [📂 녹음파일 찾아보기]                │
│     │  (클릭 시 탐색기 창이 열려 파일 선택)  │
│     │                                        │
│     ├─ [🚀 시 낭송 영상 만들기] (원클릭)     │
│     │                                        │
│     └─ 📊 상태: 제작 완료 (1분 51초)         │
│        [▶️ 영상 감상]  [⬇️ MP4 다운로드]      │
└──────────────────────────────────────────────┘
```

- **직관적 상태 표시**: 화별로 영상 제작 여부를 한눈에 식별 (⚪ 미제작 / ⏳ 렌더링 중 / 🎥 완성).
- **인라인 모달 뷰어**: 완성 즉시 화면 전환 없이 사이드바에서 [영상 감상]을 누르면 팝업 플레이어로 감상 가능.

### ③ 오직 '음성 파일'만 제공하는 3-Way 오디오 허브
글(시 원고), 그림(삽화), 자막 싱크는 시스템이 100% 자동 연결하며, 사용자는 **오직 3가지 음성 경로 중 하나만 선택**합니다.

```
                  ┌── 1) 내장 TTS 낭송 (Edge-TTS 원클릭 자동 연동)
[음성 소스 선택] ──┼── 2) 내 육성 녹음 (스튜디오 마이크로 녹음한 파일)
                  └── 3) Suno / 외부 녹음 ([녹음파일 가져오기]로 업로드)
                                │
                                ▼
         [Whisper AI: 배경음악 속 목소리 0.01초 자동 싱크]
                                │
                                ▼
         [Remotion: 삽화 켄번스 모션 + 정통 명조 자막 합성]
                                │
                                ▼
                 [완성된 고화질 슬림 MP4 자동 저장]
```

#### 세부 음원 처리 방식:
1. **내장 TTS 낭송**:
   - 별도 파일 업로드 없이, StoryBook에 내장된 고품질 인준/효정 낭송 오디오를 즉시 가져와 연결합니다.
2. **내 육성 녹음**:
   - 스튜디오 웹 인터페이스의 마이크 녹음기로 사용자가 직접 읊은 낭송 파일(`projects/{프로젝트}/music/{화}_낭송.wav`)을 자동 감지하여 투입합니다.
3. **Suno / 외부 녹음 (앱 표준: 탐색기 폴더 열기 방식)**:
   - **초보자·시니어 친화적 UI 표준 준수**: 드래그 앤 드롭은 마우스 조작이 낯선 사용자에게 창 전환 및 미스 클릭의 피로를 유발하므로 배제합니다.
   - 사이드바의 **[📂 녹음파일 찾아보기]** 버튼을 누르면 윈도우 파일 탐색기 창이 바로 열려, 사용자가 다운로드 폴더나 내 음악 폴더에서 원하는 파일(MP3, WAV, M4A 등)을 손쉽게 클릭하여 선택합니다.
   - 추가로 **[📁 음원 폴더 열기]** 버튼을 제공하여, 현재 프로젝트의 실제 음악 폴더(`projects/{프로젝트}/music/`)를 윈도우 탐색기로 직접 열어보고 관리할 수도 있습니다.
   - 선택된 파일은 시스템이 자동으로 정식 음원으로 등록하고 즉시 영상 엔진으로 인계합니다.

```text
StoryBook/
├── core/
│   ├── audio_sync_director.py      # [핵심] Whisper AI 기반 0.01초 보컬 타임스탬프 추출기

    └── poem_video_engine/          # [경량화] 시화 전용 Remotion 엔진

        └── package.json
```

## 4. 단계별 구축 일정 (4-Step Roadmap)

| 단계 | 목표 | 주요 작업 내용 |
| :---: | :--- | :--- |
| **Step 1**<br>(엔진 경량화) | **용량 최소화 & 엔진 내재화** | • `MusicStep` ➔ `tools/poem_video_engine/` 경량 구조로 이관<br>• CRF 24 슬림 인코딩 및 임시 파일 자동 클린업 루틴 작성<br>• `core/audio_sync_director.py` (Whisper int8) 공식 편입 |
| **Step 2**<br>(시화 템플릿 개발) | **정통 시화 비주얼 구현** | • KoPubWorld 바탕체(명조) 웹폰트 탑재<br>• 삽화 전용 켄 번스(Ken Burns) 카메라 무빙 컴포넌트 제작<br>• 시어 행간 여백 및 페이드인 모션 최적화 |
| **Step 3**<br>(UI 연동) | **좌측 사이드바 컨트롤 탑재** | • `index.html` 좌측 사이드바에 [시화 영상 제작] 패널 신설<br>• TTS / 육성 / Suno 3-Way 음성 선택기 구현<br>• 앱 표준 [녹음파일 찾아보기](윈도우 탐색기 창 열기) 연결 |
| **Step 4**<br>(통합 검증) | **원클릭 파이프라인 검증** | • 제11화, 제12화 시화 영상 사이드바 원클릭 생성 테스트<br>• 1분당 5~8MB 슬림 용량 및 100% 자막 칼싱크 최종 확인 |

## 5. 최종 기대 효과

1. **복잡한 작업 제로 (Zero Stress)**:  
   사용자는 음악 지식이나 자막 싱크 고민 없이, 사이드바에서 원하는 음성 파일만 고르면 1분 만에 Full HD 영상이 완성됩니다.
2. **초슬림 저장 공간**:  
   임시 파일 0Byte 유지 + 영상 파일 60% 압축으로, 40편 전편을 비디오로 제작해도 총 용량이 200~300MB 수준에 불과합니다.
3. **독보적인 시화집 미디어 확장**:  
   종이책 시화집(부크크 POD 출판)과 함께, 유튜브 쇼츠·웹 전시용으로 손색없는 품격 있는 '디지털 시 낭송 비디오 북'을 자체 보유하게 됩니다.
