# 📖 StoryBook Studio: 기억 기반 시화집 독립출판 툴킷

> **"가장 개인적인 기억이 가장 깊은 문학이자 예술이 된다."**  
> 본 프로젝트는 사용자의 실제 생애 기억을 인터뷰하여 서정시와 수채화 삽화로 엮어내고, 부크크(Bookk) POD 종이책 및 Canva 대량 조판으로 출판할 수 있도록 돕는 오픈소스 자동화 툴킷입니다.

---

## ✨ 핵심 기능

1. **✍️ 11단계 기억 기반 시화 창작 스튜디오 (웹 & CLI)**
   - **Fact Lock (사실 잠금)**: 임의적 날조 없이 실제 삶의 기억만을 바탕으로 정통 서정시와 5대 한국적 수채화 삽화를 빚어냅니다.
   - 음성 구술(마이크) 지원 및 시어 감각 사전, 원클릭 퇴고(절제/압축/운율) 탑재.

2. **🎧 4대 독립 음원 시스템 (시 낭송 3종 & 노래 1종 공존 보존)**
   - 🎙️ **육성 시 낭송** : 마이크로 직접 낭독한 시인의 진짜 목소리
   - 🤖 **AI 시 낭송** : Google Gemini 및 Edge-TTS 고품질 신경망 성우 낭송
   - 🎻 **음악 시 낭송** : Suno BGM과 함께 잔잔히 읊조리는 Spoken Word 낭송
   - 🎵 **노래 듣기** : 시를 노랫말로 편곡하여 부르는 정식 가창 음원 (Suno/Udio/YuE2)
   - 4가지 음원이 덮어쓰기 없이 각각 독립 파일로 안전하게 공존 영구 보관됩니다.

3. **🎬 고화질 시화 영상 스튜디오 (시 낭송 영상 & 노래 영상)**
   - 최대 3개의 낭송 음원 중 원하는 음원을 선택하여 원클릭 시네마틱 MP4 렌더링.
   - 16:9 와이드 가로 영상 및 9:16 유튜브 쇼츠/릴스 세로 영상 지원, 음원 파형(스펙트럼) 연출.
   - 시화집 전편 무손실 플레이리스트 영상 결합(유튜브 1시간 연속 듣기용) 지원.

4. **📖 A5 양면 펼침 출판 조판실 & 인쇄소 완제본 PDF**
   - 1페이지 쏙 맞춤 배지, 수채 블렌딩(Fade-out/in), 통합 미디어 툴바(`[🎧 오디오 ▼]` & `[🎬 비디오 ▼]`).
   - 부크크(Bookk) 인쇄소 규격 300 DPI 초고해상도 완제본 내지 및 표지 펼침면 PDF 원클릭 출력.

5. **🖼️ 독자 초대용 온라인 시화 갤러리**
   - 어르신을 위한 돋보기 글자 크기(A+/A-) 영구 기억, 먹빛 검정 붓글씨 폰트, 4대 음원 및 비디오 통합 감상실.

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 요구 사항
- **Python 3.10 이상** 설치

### 2. 설치 및 환경 세팅
```bash
# 1. 저장소 클론 (또는 다운로드)
git clone <repository-url>
cd StoryBook

# 2. 필수 라이브러리 설치
pip install -r requirements.txt

# 3. 환경 설정 파일 생성 (선택 사항)
copy .env.example .env
```
> *.env 파일에서 `GEMINI_API_KEY`를 설정하면 AI가 자동으로 시안(A/B)을 생성해 줍니다. API 키가 없어도 터미널에서 직접 원고를 작성하여 저장할 수 있습니다.*

### 3. 프로그램 실행 (웹 스튜디오 권장)
```bash
# [방법 1: 윈도우 원클릭 실행]
# 폴더 내 '시집만들기.bat' 더블클릭 (바탕화면 바로가기 및 웹 브라우저 자동 실행)

# [방법 2: 명령어로 웹 스튜디오 실행]
python run_web.py

# [방법 3: 터미널 CLI 모드 실행]
python main.py
```
> *웹 스튜디오 실행 후 화면 좌측 하단의 **[📖 큰 글씨 사용 설명서]** (`http://localhost:8000/manual`)를 누르시면 시니어·초보자 맞춤형 상세 가이드를 보실 수 있습니다.*

## 📚 2가지 출판 경로 (Canva 없이 자체 완결 vs Canva 자유 확장)

> **“Canva를 전혀 몰라도 StoryBook Studio 하나만으로 300 DPI 정식 출판까지 100% 완결됩니다.  
> Canva는 디자인 손맛을 더하고 싶은 분들을 위한 강력한 선택 옵션입니다.”**

```
[경로 1. Canva 없이 100% 자체 완결 (초보자 추천)]
  • StoryBook Studio에서 시/그림 창작 ➔ [시화집 조판 편집실] 호흡 정리
  • [출판 데이터] 탭에서 [📘 부크크 내지 완제본 PDF] & [🎨 부크크 표지 펼침면 PDF] 원클릭 다운로드
  • 부크크(Bookk), 교보문고 POD에 그대로 올리면 정식 출판 끝! (외부 툴 불필요)

[경로 2. Canva 자유 디자인 확장 (디자인 손맛 옵션)]
  • StoryBook Studio에서 [본문데이터.csv 다운로드]
  • Canva에서 공식 템플릿 열고 CSV 업로드 ➔ 3초 만에 전 페이지 자동 결합!
  • 폰트와 글자 위치를 마우스로 자유롭게 꾸민 뒤 [PDF 인쇄]로 출판!
```
