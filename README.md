# 📖 StoryBook Studio: 기억 기반 시화집 독립출판 툴킷

> **"가장 개인적인 기억이 가장 깊은 문학이자 예술이 된다."**  
> 본 프로젝트는 사용자의 실제 생애 기억을 인터뷰하여 서정시와 수채화 삽화로 엮어내고, 부크크(Bookk) POD 종이책 및 Canva 대량 조판으로 출판할 수 있도록 돕는 오픈소스 자동화 툴킷입니다.

---

## ✨ 핵심 기능

1. **✍️ 11단계 창작 동반자 인터뷰 (`main.py` -> [1])**
   - 완성된 글이 없어도 괜찮습니다. 장소, 사물, 행동, 말 한마디만 들려주면 시작됩니다.
   - **Fact Lock (사실 잠금)**: 임의적 날조 없이 실제 기억만으로 시안(A/B)과 그림 방향 카드를 도출합니다.
   - 구글 Gemini API 연동 자동 창작 지원 (API 키가 없어도 템플릿 모드로 동작).

2. **📚 마크다운 원고 자동 아카이빙 (`작품집_원고.md`)**
   - 작성된 모든 시와 삽화 정보, 진행률(`1 / 35편 완료`)을 마크다운 데이터베이스로 자동 보존합니다.

3. **📑 Canva 대량 제작(Bulk Create) 1초 연동 (`main.py` -> [3])**
   - 누적된 원고를 Canva 대량 조판 전용 `시화집_본문데이터.csv`로 일괄 추출합니다.

4. **📐 부크크(Bookk) POD 인쇄 규격 및 책등(세네카) 계산기 (`main.py` -> [4])**
   - 페이지 수와 용지 두께에 맞춘 정확한 책등(mm) 및 표지 펼침면 캔버스 크기를 자동 산출합니다.

5. **🔍 삽화 인쇄 해상도(300 DPI) 일괄 검사 (`main.py` -> [5])**
   - 생성된 그림 파일들이 인쇄 적합 기준(300 DPI / 고해상도)을 충족하는지 전수 검사합니다.

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 요구 사항
- **Python 3.10 이상** 설치

### 2. 설치 및 환경 세팅
```bash
# 1. 저장소 클론 (또는 다운로드)
git clone <repository-url>
cd StroyBook

# 2. 필수 라이브러리 설치
pip install -r requirements.txt

# 3. 환경 설정 파일 생성 (선택 사항)
copy .env.example .env
```
> *.env 파일에서 `GEMINI_API_KEY`를 설정하면 AI가 자동으로 시안(A/B)을 생성해 줍니다. API 키가 없어도 터미널에서 직접 원고를 작성하여 저장할 수 있습니다.*

### 3. 프로그램 실행
```bash
python main.py
```

## 📚 출판 워크플로우 (How it Works)

```
[1단계: 기억 인터뷰] ➔ [2단계: 원고 누적] ➔ [3단계: CSV 추출] ➔ [4단계: Canva 조판] ➔ [5단계: 부크크 출판]
    (main.py 1번)      (작품집_원고.md)     (main.py 3번)       (대량 제작 앱)       (POD 인쇄 주문)
```

1. **기억 인터뷰 진행**: `python main.py` 실행 후 `[1]`을 선택해 질문에 답하며 시와 삽화 프롬프트를 확정합니다.
2. **원고 30~35편 누적**: [작품집_원고.md](작품집_원고.md)에 작품이 차곡차곡 쌓입니다.
3. **CSV 추출**: `[3]`번 메뉴를 눌러 `시화집_본문데이터.csv`를 생성합니다.
4. **Canva 대량 조판**: Canva에서 A5 2페이지 템플릿(좌측: 삽화, 우측: 시)을 만들고, '대량 제작' 기능으로 CSV를 연결해 한 번에 80페이지 책을 완성합니다.
5. **PDF 인쇄 및 출판**: Canva에서 `PDF(인쇄) - PDF 평탄화 체크`로 내보낸 뒤 부크크에 등록합니다.
