# MusicStep Lyric Video Template v1

음악, 커버 이미지, SRT 가사를 넣으면 완성된 리릭비디오를 만듭니다.

## 준비물과 사용법

1. 받은 ZIP을 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. 압축을 푼 **MusicStep-LyricVideo-v1 폴더 전체**를 Codex에서 엽니다.
3. `input` 폴더에 **음원 1개 + 커버 이미지 1개 + SRT 1개**를 넣습니다.
4. Codex에 **“리릭비디오 만들어줘”**라고 요청합니다.
5. 완료 안내가 나오면 `output` 폴더의 **[음원파일명]_lyric-video.mp4**를 확인합니다.

예: `가을 하늘.mp3` → `가을 하늘_lyric-video.mp4`

세 파일의 이름이 서로 달라도 됩니다. 한글·영문·숫자·공백을 사용할 수 있습니다. `input` 안에 다른 폴더를 만들지 말고 바로 넣어주세요. 다음 곡은 기존 입력 세 파일을 다른 곳으로 옮기고 새 세 파일을 넣으면 됩니다.

## 처음 한 번 필요한 준비

- 프로젝트 폴더의 파일을 읽고 명령을 실행할 수 있는 **Codex 환경**이 필요합니다. 특정 AI 모델이나 별도의 Remotion Skill은 필요하지 않습니다.
- **Node.js 22 이상과 함께 설치되는 npm**이 필요합니다. 없다면 Codex가 “리릭비디오를 만들려면 Node.js 설치가 필요합니다. 설치를 진행할까요?”라고 묻습니다. 승인하면 설치와 확인을 거쳐 원래 영상 제작을 계속합니다. 별도로 “설치해줘”나 “다시 만들어줘”라고 요청할 필요가 없습니다. [Node.js 공식 사이트](https://nodejs.org/)의 LTS 버전을 권장합니다. 설치 시 운영체제나 Codex의 권한 승인 화면이 추가로 나타날 수 있습니다. 자동 설치가 불가능하면 Codex가 공식 설치 페이지와 다음 단계를 안내합니다. 수동 설치 또는 앱 재시작 때문에 완료를 자동 확인할 수 없는 경우에는 같은 대화에 “완료”라고 알려주면 제작을 이어갑니다.
- 첫 제작에는 인터넷 연결이 필요합니다. 프로젝트용 구성 요소, 음악 처리 도구, 렌더링용 브라우저를 자동으로 받습니다. npm 저장소, GitHub, Chrome 다운로드 서버에 연결할 수 있어야 합니다.
- 폴더 쓰기 권한과 충분한 여유 공간이 필요합니다. 설치 파일·임시 영상·이전 결과가 쌓이므로 수 GB 이상의 여유 공간을 준비하세요. 제작 시간은 컴퓨터 성능과 곡 길이에 따라 달라집니다.
- 시스템 전체에 영향을 주는 설치나 관리자 권한 작업은 Codex가 동의를 받은 후 진행해야 합니다. 프로젝트에 필요한 구성 요소는 이 폴더 안에 설치됩니다.

### macOS

Apple Silicon 또는 Intel Mac용 Node.js를 사용합니다. 폰트나 FFmpeg를 따로 설치할 필요가 없습니다. 다운로드한 실행 도구가 보안 프로그램에 차단되면 Codex에 오류를 전달하세요. 보안 기능을 무조건 끄지 마세요.

### Windows

**Windows x64용 Node.js**를 사용합니다. 현재 배포판은 Windows ARM64 네이티브 Node.js를 지원하지 않습니다. ZIP을 짧은 로컬 경로에 풀면 긴 경로·동기화 충돌을 줄일 수 있습니다. 한글·공백 경로 자체는 지원하도록 작성되었습니다.

Windows용 실행 경로와 도구 선택은 코드로 점검했습니다. **기존 v1은 사용자가 Windows 신규 무료 계정의 Codex Luna Light 환경에서 전체 렌더링 성공을 확인했습니다(사용자 보고, 2026-10-14). 이번 설치 동의 절차 개정은 실제 Node.js 미설치 Windows/macOS에서 아직 재시험하지 않았습니다.**

## 지원 파일

| 종류 | 지원 형식 | 개수 |
|---|---|---|
| 음악 | MP3, WAV | 1개 |
| 커버 | JPG, JPEG, PNG | 1개 |
| 가사 | SRT (UTF-8 권장, BOM 있는 UTF-16 지원) | 1개 |

확장자의 대소문자는 관계없습니다. 연결 파일/바로가기 대신 원본 파일을 복사해주세요. SRT는 가사 문장과 표시 시간을 담은 파일입니다. 음악을 자동으로 받아쓰거나 SRT를 새로 만드는 기능은 포함하지 않습니다.

영상은 1920×1080, 30fps, H.264/AAC MP4로 만들어집니다. 길이는 실제 음원 길이에 맞춰 정해지며 영상 프레임 단위로 최대 약 1/30초 올림될 수 있습니다.

## 문제가 생겼을 때

| 안내/상황 | 해결 방법 |
|---|---|
| 음원 파일이 없음 | `input`에 MP3 또는 WAV 한 개를 넣습니다. |
| 커버 이미지가 없음 | JPG, JPEG 또는 PNG 한 개를 넣습니다. |
| 가사 파일이 없음 | SRT 한 개를 넣습니다. TXT 파일의 확장자만 바꾸지 마세요. |
| 같은 종류가 여러 개 | 사용할 한 개만 남기고 나머지는 다른 폴더로 옮깁니다. Codex가 임의로 선택하거나 삭제하지 않습니다. |
| Node.js가 없음/버전이 낮음 | Codex의 설치 동의 질문에 답합니다. 승인 후 설치 확인과 원래 제작이 이어집니다. 수동 설치가 필요한 경우 안내에 따라 설치하고 “완료”라고 알려주세요. |
| 구성 요소 설치가 필요함 | 정상적인 첫 실행 과정입니다. 인터넷 연결을 유지하고 기다리세요. 실패하면 Codex에 다운로드/권한 확인을 요청합니다. |
| 가사 시간 오류 | SRT의 시간 형식·순서·겹침·음원 끝 이후 시간을 확인합니다. Codex는 원본 가사의 의미나 시간을 임의 수정하지 않습니다. |
| 글자가 깨짐 | SRT를 UTF-8로 다시 저장합니다. |
| 아주 긴 가사를 표시할 수 없음 | 최소 글자 크기로 두 줄에도 들어가지 않는 문장입니다. 안내를 확인하고 사용자가 문장/구간 분할 여부를 결정합니다. |
| 제작이 중단됨 | Codex에 “이전 작업 상태를 확인하고 다시 만들어줘”라고 요청합니다. 중단된 프레임부터 이어 붙이는 기능은 없으며 제작을 다시 시작합니다. |
| 다른 작업이 진행 중이라는 안내 | 실행 중인 작업이 있는지 Codex가 확인하게 하세요. 임의로 잠금 파일을 지우지 마세요. |
| output에 새 파일이 없음 | 아직 제작 중이거나 실패한 상태입니다. 완료 안내를 확인하고 Codex에 제작 기록 확인을 요청합니다. 기존 영상이 있다고 이번 제작이 성공한 것은 아닙니다. |

완성된 영상은 재생 검증을 통과한 뒤에만 `output`에 저장합니다. 같은 이름의 기존 영상은 `output/previous/실행ID/`에 보관합니다. 작업 중 파일과 진단 기록은 숨김 폴더 `.musicstep/runs/`에 있습니다. 원본 입력은 변경하지 않습니다.

## 자주 묻는 질문

**명령어와 영상 코드를 알아야 하나요?** 아니요. Codex가 정해진 제작 명령을 대신 실행합니다. 제작에 필요한 명령은 `npm run make-video` 하나이며 사용자가 직접 입력할 필요는 없습니다.

**다른 Codex 모델로 바꾸어도 되나요?** 파일 접근과 명령 실행이 가능하면 됩니다. 영상은 AI가 매번 새로 디자인하는 것이 아니라 고정된 코드와 입력으로 만듭니다. 운영체제·CPU·디코더에 따른 미세한 수치/인코딩 차이까지 MP4의 바이트 단위 일치를 보장하지는 않습니다.

**폰트를 설치해야 하나요?** 아니요. 승인된 디자인의 Pretendard Variable 폰트를 프로젝트에 포함했습니다. 시스템 폰트 설치에 의존하지 않습니다. 폰트는 SIL Open Font License 1.1로 재배포하며 [원본 라이선스](https://github.com/orioncactus/pretendard/blob/v1.3.9/LICENSE)와 패키지의 `licenses/PRETENDARD-OFL.txt`를 확인할 수 있습니다.

**길이가 긴 음악도 되나요?** 곡 길이는 자동 처리합니다. v1은 일반적인 노래 길이를 대상으로 합니다. 오디오 분석의 고정 메모리 제한 때문에 약 33분 이상은 지원 범위를 벗어나며, 그보다 짧아도 컴퓨터 메모리/디스크에 따라 제한될 수 있습니다.

**특수문자가 있는 제목은요?** 영상 제목은 원래 음원 이름을 사용합니다. 출력 파일명만 Windows에서 허용하지 않는 문자를 `_`로 바꾸고, 매우 긴 이름은 짧게 줄여 구분용 값을 붙입니다. 일반적인 한글·영문·공백 이름은 유지합니다.

**상업적으로 사용해도 되나요?** 음원·이미지·가사에 필요한 권리는 사용자가 확보해야 합니다. 포함/다운로드되는 도구에도 각각의 라이선스가 있습니다. 특히 Remotion 4.0.532의 포함 라이선스는 개인·비영리·직원 3명 이하 영리 조직 등에 무료 조건을 제공하며, 그 외 조직에는 회사용 라이선스가 필요할 수 있습니다. `licenses/REMOTION-LICENSE.md`와 [Remotion 안내](https://www.remotion.dev/license)를 확인하세요. 이 템플릿은 제3자 저작물의 권리를 별도로 부여하지 않습니다.
